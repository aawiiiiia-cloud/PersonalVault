# BlockSuite EdgelessEditor 验证原型

这是卡片编辑器替换前的独立验证页，不会读取或修改现有知识库。代码固定使用 BlockSuite 0.19.5，避免其图标依赖解析到不兼容版本。交互改造使用 `prototype-v10` 浏览器测试库，旧原型测试数据不会再加载。

## 启动

在此目录执行：

```powershell
pnpm install
pnpm dev
```

浏览器打开 `http://127.0.0.1:5173/`。`pnpm build` 可以检查生产构建。

## 已验证

- EdgelessEditor 在本机 Chromium 中加载，默认展示一张富文本笔记。
- 笔记文字修改后刷新仍在。
- 本地图片作为画布图片块出现，刷新后仍能显示；插入时会核对 Blob 是否已存入本地资源库。
- 画布文档用 Yjs 的 IndexedDB 持久化；图片 Blob 用 `IndexedDBBlobSource` 持久化。两者必须同时存在，否则图片引用会失效。
- 补入 `@toeverything/theme` 样式后，画布点阵会跟随平移和缩放；正文笔记和独立文字框都有可见边界。
- 普通拖拽框选松开后会结束。旧测试库曾残留孤立的 surface 模型，导致 BlockSuite 工具查错画布层；目前改用干净测试库，并在工具初始化时修正 surface 视图查找路径，保留框选状态清理兜底。
- 当前可见工具栏及常见弹窗文案做了中文适配。BlockSuite 0.19.5 的预置组件没有完整的语言注册接口，正式集成前仍需逐项检查所有深层菜单和模板；用户输入的正文不会被自动翻译。
- 工具栏只显示选择、富文本框、曲线、画笔、橡皮擦和删除。选择工具下拖动空白处框选，双击空白处创建快速注释；双击已有文本框进入编辑。空格加拖动移动画布；滚轮在空白处缩放画布，在超长文本框内滚动文字。画布工具切换快捷键已关闭，Ctrl+Z 可撤销删除。
- 选择“富文本框”后，在空白处拖动可决定宽高，单击则用默认大小创建。快速注释使用 240×92 的初始尺寸。两者都使用 BlockSuite 笔记块，避开独立文字模型与笔记模型的焦点冲突，以及内置笔记工具在此独立原型中的报错。
- 文本框单击选中，双击编辑。超长内容在框内滚动，悬停时不再展开额外预览，编辑时背景边界不再外扩。
- 双击文本框时将 BlockSuite 的文字选区放进首段，由外层原生编辑宿主持有焦点；不再反复聚焦嵌套输入区。拼音组合输入跳过画布快捷键，正文选区内的 beforeinput 不再被拦截。空白文本框隐藏默认占位提示。
- 单个文本框缩放固定对侧边缘，最小尺寸为 120×48 画布单位；拖过对侧不会翻转或带动整个框移动。宽高按笔记自身缩放比例换算。折叠内容的悬浮预览彻底隐藏，内容仍在框内滚动。
- 单击文本框可移动或缩放；双击进入编辑后仍可拖动四边、四角缩放，保持文字选区。单个文本框移除原生蓝色选框及圆形控制点，保留卡片自身的细灰色轮廓。
- “选择”和“曲线”图标悬停时轻微上移、旋转，与其他工具的动画呼应。
- 框选时禁止浏览器跨文本框选中文字，退出编辑时清理正文选区。单击、双击编辑和多选均用每张卡片自身的蓝色边缘表示选中；多选文本框不显示外层大选框。拖动任一所选文本框的边缘同步调整所选文本框的尺寸，各框左上角坐标保持不变，整体移动仍由原生画布处理。
- 底部工具栏复用初版画布的纸张布局、铅笔和橡皮擦图形及悬停效果，保留中文标签。资源来源与许可证见 `public/assets/icons/ATTRIBUTION.md`。

本轮生产构建与缩放边界计算检查通过。真实 Windows 拼音输入法的候选词流程尚未完成验证：电脑操作工具因无法可靠识别浏览器 URL 而中止；直接插入中文的测试不能替代此验证。

页面提供本地图片或视频选择入口，默认视频单文件上限为 10 MB；目前没有完成真实本地视频文件的交互验证。

## 正式接入前的工作

1. 将每张卡片的 BlockSuite 文档和媒体文件一起保存到知识库目录。IndexedDB 只能作缓存，不能作为唯一副本。文件写入需要临时文件、校验、原子替换和可恢复的版本号。
2. 将画布的文字映射到卡片搜索和导出。画布位置与层级另存结构化数据，不强行塞进 Markdown。
3. 大视频接入知识库现有素材服务，避免 10 MB 的默认附件限制和浏览器数据库膨胀；验证拖动、缩放、播放与撤销。
4. 在正式替换卡片编辑区前，验收新建卡片的正文位置和焦点、注释框的尺寸与连线、视频播放、框选和抓手操作。

此原型用于验证编辑器选择。不要在这里记录需要长期保留的数据。
# 工作台集成

工作台【知识】【项目】【资料】卡片的正文编辑区使用本目录的画布。修改画布源码后，在仓库根目录运行 `pnpm build:canvas`，构建产物写入 `canvas-editor/`，供浏览器版和 Electron 桌面版共同加载。

每张卡片的画布按卡片 ID 单独保存在知识库的 `系统/自由画布/<卡片ID>.json`。首次打开旧卡片时会将现有正文与图片导入画布；首次保存后，旧正文仍保留在卡片的 `legacyContent` 字段，便于核对迁移结果。
