01结论速览

对个人应用而言，字体问题在 2026 年已经基本「免费化」：高质量中文开源字体（OFL 协议）覆盖正文、宋体、楷体、标题黑全部需求，唯一要注意的是不要用系统自带的微软雅黑做内嵌分发（方正授权限制），以及华为鸿蒙字体「免费但不可修改、需开发者账号」。

如果只下载三个：思源黑体（正文/UI 兜底，最稳）＋ 霞鹜文楷（阅读/引文气质）＋ Inter 或 MiSans（现代 UI 感，含优秀西文数字）。等宽场景加 JetBrains Mono 或 更纱黑体。

02下载渠道：去哪里拿到完整字体

07美学自评维度（判断框架）

既然美学由你判断，以下 8 个维度是对比候选字体时最该盯着看的地方——建议直接在应用真实界面里 A/B 替换，而不是看字体官网的展示海报。

字面率与字腔字面大（MiSans、OPPO Sans）显得现代饱满；字面小（思源系）更疏朗安静。直接影响同样字号下的「密度感」。
重心高低重心高的字体（如楷体、部分宋体）显得轻盈古典；重心低且居中（思源黑）更稳定工具感。
笔画对比度宋体/楷体横细竖粗，有书写性；黑体均匀，克制。对比度高的字体在细线、留白多的界面里更出味道。
x-height（西文）x 字高大的西文（Inter、JetBrains Mono）小号更清晰；低的（IBM Plex）更优雅。与你中文的灰度要匹配。
中英混排基线同一行中英文是否「坐」在同一水平线、字号视觉是否等大。MiSans、更纱黑体做过专门优化；混排是工作台类应用最高频场景。
数字性格看 0/1/6/9 的区分度、是否有表格数字（tabular-nums）。时间戳、计数、ID 多的应用，数字比字母更常出现。
小字号渲染12–14px 下笔画是否糊、粘连。Windows 下尤其要在真实缩放开真实界面看，不要只看大号样张。
字重梯度标题/正文/辅助三层能否靠字重拉开（400/500/700）。字重越多（MiSans 10 档、Inter 可变）层级越细腻。

08前端落地技术要点

知行台是 Electron 本地应用，字体可以完全离线打包，没有加载延迟顾虑，主要关注体积与渲染：

1. 本地 @font-face，离线打包

/* 字体文件放 assets/fonts/，随应用分发 */
@font-face {
  font-family: "Noto Sans SC";
  src: url("assets/fonts/NotoSansSC-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}
:root {
  --font-ui: "Inter", "Noto Sans SC", "PingFang SC", sans-serif;
  --font-read: "LXGW WenKai", "Noto Serif SC", serif;
  --font-mono: "JetBrains Mono", "Sarasa Mono SC", monospace;
}

2. 体积控制：子集化 + WOFF2

# 全量思源黑 SC 约 16MB/字重；用 pyftsubset 裁到常用字后可到 1-2MB
pip install fonttools brotli
pyftsubset SourceHanSansSC-Regular.otf \
  --unicodes="U+4E00-9FFF,U+3000-303F,U+FF00-FFEF,U+0020-007E" \
  --flavor=woff2 --output-file=NotoSansSC-Regular.woff2

霞鹜文楷直接选 Lite 版（已剔除罕用字，专为内嵌场景设计）；西文字体本身很小（Inter 单字重 WOFF2 约 100KB），全字重打包也无压力。可变字体（Variable Font）一个文件覆盖全部字重，中文可变版体积也大，谨慎选择。

3. 渲染细节

· 正文中文建议 letter-spacing: 0，标题中文可微加 0.02–0.05em 呼吸感。
· 数字列加 font-variant-numeric: tabular-nums 对齐（Inter / MiSans 均支持）。
· 中英混排在 CSS 里用 font-family 顺序回退即可（西文在前、中文在后），无需 markup 包裹。
· Electron（Chromium）默认 DirectWrite 渲染，黑体系在 125%/150% 缩放下表现好；楷体类建议正文不小于 15px。
